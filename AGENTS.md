# Development Rules

## Auto-Apply Skills

Before writing any code, you MUST use the `read` tool to load the relevant skills from `~/.neo/agent/skills/`:

- `~/.neo/agent/skills/ui-ux-pro-max/SKILL.md` — load before writing any frontend/UI/HTML/CSS code
- `~/.neo/agent/skills/awesome-design-md/SKILL.md` — load when choosing design patterns or component approaches
- `~/.neo/agent/skills/backend-best-practices/SKILL.md` — load before writing any server/API/security/database code

The skills contain condensed rule sets. Follow them in every build.

## Project Context

- `server/` — backend (schema, API, auth, deployment details in `DEPLOYMENT.md`)
- `web/` — frontend
- `PROJECT_SUMMARY.md` — full project overview
